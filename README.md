# Online Boutique

A Django-based e-commerce project for managing categories, products, carts, and orders.

## Prerequisites

- Python 3.8+  
- pip  
- virtualenv (optional but recommended)

## Setup

1. **Clone the repo**  
   ```bash
   git clone https://github.com/Arunimavpa/Online_boutique.git
   
   cd Online_boutique
   

2. **Create & activate a virtual environment (Windows)**

   ```bash
   python -m venv .venv
   .venv\Scripts\activate
   
3. **Install dependencies**
   ```bash
   pip install -r requirements.txt
   
## Database
1. **Generate tables**
    ```bash 
    python manage.py migrate 
2. **Running the Development Server**
    ```bash 
    python manage.py runserver
